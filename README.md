# Data Cleaner — Limpeza Inteligente de Dados

Aplicativo web desenvolvido para facilitar a **limpeza, padronização e preparação de dados** a partir de arquivos Excel e CSV.

O projeto foi criado como uma aplicação prática para transformar arquivos com inconsistências em uma base mais organizada e pronta para análise.

## 🎯 Objetivo

Automatizar etapas comuns de preparação de dados, reduzindo tarefas manuais e permitindo visualizar as alterações realizadas antes de exportar a base tratada.

## ✨ Funcionalidades

O usuário pode selecionar quais tratamentos deseja aplicar ao arquivo, incluindo:

- 📅 Padronização de datas
- 💰 Tratamento de preços e valores
- 🔤 Padronização de textos
- 🗑️ Remoção de registros duplicados
- ⬜ Tratamento de linhas vazias
- 📋 Padronização de cabeçalhos
- 🚫 Tratamento de valores nulos
- ␣ Remoção de espaços extras
- 🔠 Padronização de maiúsculas e minúsculas
- ✂️ Tratamento de caracteres especiais
- 📞 Padronização de telefones
- 📍 Padronização de CEP
- 🪪 Padronização de CPF/CNPJ
- 📧 Tratamento de e-mails
- 🗺️ Padronização de estados (UF)
- 🔁 Identificação de colunas duplicadas
- 📈 Tratamento de outliers de idade

Após o processamento, a aplicação apresenta:

- indicadores resumidos da limpeza;
- relatório das alterações realizadas;
- visualização dos dados tratados;
- navegação entre diferentes abas da planilha;
- exportação da base limpa para Excel.

## 📂 Formatos aceitos

- `.xlsx`
- `.xls`
- `.csv`

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- [SheetJS](https://sheetjs.com/) para leitura e geração de planilhas
- Google Fonts (Inter e JetBrains Mono)

## 💡 O que este projeto demonstra

Este projeto reúne conhecimentos de **desenvolvimento web, manipulação de dados, tratamento de inconsistências e experiência do usuário**, conectando tecnologia com uma necessidade real de análise de dados.

A proposta é transformar uma tarefa operacional e repetitiva em um fluxo mais simples, visual e automatizado.

## 🚀 Como utilizar

1. Abra a aplicação.
2. Selecione ou arraste um arquivo `.xlsx`, `.xls` ou `.csv`.
3. Escolha os tratamentos que deseja executar.
4. Clique em **Limpar dados**.
5. Analise o relatório e a prévia dos dados tratados.
6. Exporte o arquivo Excel limpo.
